# Capability #25 — NEXUS Ventaja GEO/AEO / Presencia en IA

This capability extends the canonical `@nexus/generative-readiness` package. It does not create a parallel GEO engine.

Implemented scope:
- tenant / organization / brand scoped presence reports;
- replay-verifiable binding to canonical page readiness evidence;
- explicit `NOT_VERIFIED` / `UNAVAILABLE` external visibility states;
- no fabricated provider inclusion, citation, ranking, traffic, or business outcome claims;
- bounded operational CLI with strict top-level request fields and operator cancellation;
- advisory provider proposal boundary that carries Claude/OpenAI instructions as data without repository, graph, deployment, approval, or transaction authority;
- single-writer NEXUS execution boundary documented for later provider integrations.

External provider observations remain outside this capability unless real provider evidence is supplied through the governed execution boundary. A readiness result alone never upgrades to observed provider visibility.
