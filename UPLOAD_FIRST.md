# UPLOAD FIRST

Upload the CONTENTS of this repository directory to the root of the empty GitHub repository `nexus-engine`.

Do not upload the ZIP itself as a repository file.

Suggested first commit message:

`Initialize NEXUS V6 consolidated R1`

After the commit, open the **Actions** tab and select:

`NEXUS V6 Closeout — staged compile`

If GitHub did not start it automatically, use **Run workflow** on `main`.

When a job fails, preserve the complete first failed-job log. Do not manually refactor the repository before the failure is reviewed.
