# NQC V2 — SVR-EXEC-CAPITAL-001: Does the certified one-shot actually qualify as a financed, competitive Ethereum SVR backrun?

## Decisive commercial question

The PR725/PR726/PR727 historical one-shot **mechanically** demonstrated a successful single local EOA CREATE in a selected fork state, with 3,914,680 `gasUsed`, original EOA tx gas limit 5,089,056, and 2,273.989378 USDC returned from flash loan, liquidation and swap **before native fees/inclusion**. PR738 later correlated one other historical HF-triggering WETH/USDT report with a public Flashbots MEV-Share archive hint, but did **not** demonstrate NQC first receipt, builder cutoff, paid inclusion, recurring capture or nonrecourse financing. The currently inherited `NqcV2OneShotAtomicLocal` source is deliberately hard-coded to Ethereum block 26,142,067/68 and has an exact borrower/surplus witness from that historical case.

This gate tests whether that **actual certified source, unchanged**, can be promoted as an SVR mainnet backrun with `OWN_CAPITAL=0`, versus merely passing an isolated historical EVM replay. It **must** reject promotion when the same source is bound to obsolete historical blocks, contains no explicit native `block.coinbase` bid path, or lacks an independently committed native-gas payer. A working public hint decoder is *not* an executable, financed winning auction strategy.

## What the new offline source and money gate actually does

1. Assert byte-exact original Solidity Git blob, strict code source anchors, historic block/parent guards, source-specific gross surplus in USDC, and absence of native direct coinbase payment in that original source.
2. Compute EIP-1559 fee and minimum **upfront ETH gas escrow** from exact gas limit `gasLimit * maxFeePerGas` (fee-cap balance needed to submit a native EOA transaction; exact effective fee on inclusion may be lower). Separate receipt gas `gasUsed * (baseFee + priorityFee)` and never subtract priority twice.
3. Apply **integer-only** hypothetical ETH/USD conversion. The experiment uses a clearly labeled **illustrative USD 2,500/ETH**, not the original WETH/USD of a different block or a current forecast. Three fee/bid stress cases are **scenario arithmetic**, not observable auction clearing prices, projected P&L, financier quotations, or deployable onchain bids. Dollar values are in USDC micro-units; round charges **up** conservatively. The historical surplus already reflects original flash premium and DEX fees, so never subtract them twice.
4. The truthful terminal outcome for the original source is **`BLOCKED_NOT_A_PRODUCTION_SVR_BID_EXECUTOR`** even when a hypothetical residual is positive. The gate does not accept self-attested sponsor booleans or user-owned native gas and does not sign or construct a raw transaction.
5. Preserve exact HEAD/TREE, source, tests, contract, money scenarios, test logs and SHA-256 manifests as immutable CI artifact. Fail hard on altered source, malformed money, nonzero unsupported source options or a false `LIVE`/`RMC_CLOSED` assertion.
