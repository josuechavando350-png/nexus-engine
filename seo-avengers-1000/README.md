# SEO Avengers 1000

This package extends the audited production registry from M001-M800 to an exact M001-M1000 candidate. M001-M800 remain delegated to `seo-avengers-800`; M801-M1000 are implemented locally with the exact M1801-M2000 source map.

The local runtime is deterministic and evidence-only: canonical NFC JSON receipts, int64 integers, no floats, no wall clock, no randomness, no provider/network/database writes, and the `avengers1000_v1_` algorithm namespace. The 200 local modules are split into 50 semantic/NLP audits, 50 HTML/stream audits, 50 Edge/perimeter parity audits, 49 relational/persisted-evidence audits, and M1000 terminal composition certification.

M1000 verifies the exact M001-M1000 catalog, the M1801-M2000 to M801-M1000 source map, 200 unique operations, delegation of M001-M800 to `seo-avengers-800`, absence of M1001, and full structured composition evidence before deriving its own canonical composition hash.

`CONFIG_SEO_AVENGERS_1000` is deny-by-default. When disabled, no M801-M1000 modules execute. When enabled with valid evidence, exactly 200 local modules execute.

The dedicated verifier must chain `seo-avengers-800/scripts/verify.sh`, compile and run the 1000 tests, prove exact mapping/catalog cardinality, reject fabricated/coupled content and side-effect clients, and reject floats, wall clock, randomness, and runtime assertions. The pull-request workflow checks out the exact PR head and permits changes only under `seo-avengers-1000/**` plus its dedicated workflow. Cano paths remain forbidden.

This branch is not merge-ready until the full chained verifier and exact-head GitHub checks are green. No PR should be merged from this README alone.
