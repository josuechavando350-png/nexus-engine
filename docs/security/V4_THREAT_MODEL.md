# V4 Threat Model
Threats include prompt/tool/memory/retrieval poisoning, malicious model output, goal hijacking, privilege escalation by delegation, confused deputy, replay, stale plan execution, forged observations/checkpoints and provider compromise. Controls in this snapshot: typed contracts; grounded evidence requirement; capability-subset delegation; side-effect-free replay; speculative-world separation; bounded reasoning/recovery; provider-neutral inference; mandatory return to V3 dispatch gates. Remaining risks require compiled tests, fuzzing and integration tests before V4 closure.
