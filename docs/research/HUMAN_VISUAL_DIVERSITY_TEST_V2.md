# Human Visual Diversity Test V2

Purpose: test the question automation cannot answer reliably yet.

## Protocol

1. Capture the same viewport family for all four V2 probes (desktop and mobile).
2. Remove/obscure logo, brand name and distinctive palette where practical.
3. Randomize order.
4. Show pairs to at least 5 independent reviewers who did not build the probes.
5. Ask only:

> Without logos, names and brand colors, do these Experiences look like they came from the same template?

6. Record `yes`, `no`, and optional reason. Do not coach reviewers with NEXUS terminology.
7. Also ask which structural cues caused the judgment (opening, navigation, section rhythm, CTA, geometry, media, motion).

## Decision

V2 must not claim the human diversity gate as executed until this protocol is actually run. Structural tests can pass while human perception still detects author habit.
