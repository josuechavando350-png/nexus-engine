# V6 Technology Value / Due-Diligence Gate

V6 is not allowed to claim that NEXUS is worth US$1M merely because this file exists or because the roadmap is implemented.

Before the technology asset is presented as plausibly supporting a US$1M+ technology-value argument, provide evidence for all of the following:

1. end-to-end business/industrial problem solved;
2. reproducible clean deployment;
3. supported hardware/software integrations;
4. measured throughput and p50/p95/p99 latency;
5. CPU/RAM/disk/network benchmark context;
6. node/zone/region failure injection and recovery;
7. offline operation and reconciliation;
8. no duplicate physical effect after replay/reconnect;
9. failover/replication evidence;
10. signed update and rollback rejection demo;
11. fleet rollout and quarantine demo;
12. federation least-privilege test;
13. documented proprietary IP inventory;
14. replacement-difficulty analysis with engineering effort assumptions;
15. dependency replacement paths;
16. threat model and trust boundaries;
17. SBOM and dependency/security audit;
18. immutable/reproducible benchmark dataset and commands;
19. API/SDK usable by an external team;
20. operational runbooks and observability;
21. external engineer can deploy from docs;
22. exceptional human-facing Experience, if one is part of due diligence, produced through the Art Direction process rather than a generic dashboard.

Any unavailable item must remain `NOT TESTED`, `NOT MEASURED` or `NOT IMPLEMENTED`. Several missing items mean the US$1M+ engineering-value target is not yet defensible.
