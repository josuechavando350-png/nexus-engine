# Recipes — strategies, not templates

A Recipe is a **compositional strategy** expressed as narrative stages and abstract moves such as:

- sequence
- juxtapose
- layer
- isolate
- interrupt
- anchor
- reveal
- echo

V2 ships five compositional strategies as evidence/probe tools:

- `editorial-sequence`
- `media-immersion`
- `dense-index`
- `asymmetric-field`
- `continuous-bands`

They contain no brand colors, radii, fonts, component names, CSS classes or React code. `defineRecipe()` rejects UI-specific keys.

A Recipe can guide many unrelated visual outcomes because it defines relationships, not finished sections. Apps are expected to depart visually even when they share a Recipe, provided the DNA and project rationale demand it.
