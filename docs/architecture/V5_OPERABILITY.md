# V5 Operability

Operational surfaces: resource registry, authorization decisions, audit events, alerts, usage/cost and health/telemetry from V3/V4.

OpenTelemetry is the preferred interoperability boundary for traces/metrics/logs, not NEXUS's internal evidence model. Alerting and evidence remain domain records so observability vendors can be replaced.

## Human console
A web console is required for V5 closure, but visual implementation is intentionally not fabricated in this build candidate. NEXUS's design process requires Reference → Visual Dissection → Art Direction DNA → One Screen → Human Approval before implementation. API/contracts are ready for that slice.
